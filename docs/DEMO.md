2. Положить ответ API организаторов в `data/DEV.json` (массив, records или data.records).

## Опорные ответы жюри

- «Откуда экономия?» — число диалогов × минуты / 60; затраты человека — часы × ставка. Затраты с ИИ — все сохранённые оценки выбранных диалогов плюс время разбора грубых ошибок, ручной проверки и апелляций. Пересечения считаются один раз. Это сценарная оценка, не замер рабочего времени.
- «Почему неизвестна цена?» — у части оценок нет `cost_usd`; приложение показывает известную часть и не считает денежную экономию до появления полной стоимости. Неподсчитанные неудачные вызовы и инфраструктура не включены.
- «Что значит риск?» — диалог с флагом грубой ошибки после решений по апелляциям. Это не сумма предотвращённого ущерба и не независимое подтверждение нарушения.
- «Откуда коучинг?» — правила версии чек-листа и финальные ответы. Приоритет — грубые нарушения, затем суммарная потеря по весу. Есть пример и цель для проверки наставником; обучение само по себе не считается завершённым.
- «Что при медленном API?» — показать статус фоновой задачи. Если ответ не успел, открыть заранее сохранённый результат и прямо назвать его предыдущей оценкой; не объявлять новый запуск завершённым.

- Пройти сценарий вслух с секундомером; контрольные точки 0:40, 1:10, 2:35, 3:30 и финиш до 5:00. Записать фактическое время, ID диалога, модель и стоимость. Если не укладываемся, сократить комментарии к сводке; замену критерия и апелляцию оставить.
- Проверить экономию: изменить минуты и ставку, убедиться в пересчёте; неизвестная цена не должна давать бесплатный ИИ. Проверить коучинг: ссылка ведёт к нужной оценке и реплике, после отмены нарушения приоритет исчезает.
- Отдельная проверка замены: версия N неизменна; в N+1 старый ID удалён, новый добавлен; повторная оценка использует N+1 и содержит новый ответ. Старые оценки и апелляции остаются привязаны к N.
- Отдельная проверка апелляций: подтвердить без изменения итога; изменить два разных критерия последовательно — финальный итог учитывает оба решения. Пустую причину, запрещённый N/A, число вне шкалы и повторное решение отклонять.
- Проверить RU/KZ/EN, переход к доказательству, истёкшую ссылку на аудио, ошибку LLM и повторный запуск после ошибки.
